# 300 откликов. Один оффер.

[Играть в браузере](https://tim4757.github.io/300-applications-one-offer/)

Симулятор найма: закрой три вакансии — разработчика, продуктового аналитика и менеджера проектов. На каждую приходит 300 откликов. Выбери трёх финалистов, проверь их опыт и предложи работу одному из них.

Рекомендации вымышленного ИИ, красивые резюме и премиум-аккаунты не гарантируют удачный найм. Общий фонд зарплат — 780 000 ₽ в месяц. После каждого решения игра показывает результат и возможную экономию.

Все кандидаты, компании и события вымышлены. Игра работает на телефоне и компьютере; прогресс хранится только в текущем браузере. Внешние AI API и серверная база данных не используются.

## Локальный запуск

Открой `index.html` или запусти любой статический HTTP-сервер в этой папке. Проект написан на HTML, CSS и JavaScript; сборка и установка зависимостей не нужны.

## Обновления

GitHub Pages публикует корень ветки `main`. Для обновления замени нужные файлы и отправь коммит в эту ветку. Сохраняй относительные пути к ресурсам.
